# Салон красоты «Люмьер» — демо-сайт

Одностраничный демо-сайт салона красоты: адаптивный, на чистом HTML/CSS/JS, без сборки и зависимостей.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: первый экран с кнопкой «Записаться», о салоне, галерея, услуги с ценами, отзывы, контакты с картой, форма записи |
| `policy.html` | Отдельная страница политики конфиденциальности |
| `style.css` | Все стили (светлая тема, адаптив от 320 px) |
| `script.js` | Мобильное меню, маска телефона, валидация формы, год в подвале |
| `favicon.svg` | Иконка сайта |
| `images/` | Фотографии |

## Что реализовано

- **Первый экран с формой записи** — главный оффер, кнопка «Записаться», форма записи в карточке справа (на телефоне — сразу под заголовком), ниже — преимущества и рейтинг.
- **Услуги с ценами** — 4 категории (волосы, ногти, лицо и тело, макияж и ресницы).
- **Отзывы** — 3 отзыва с оценками.
- **Контакты** — адрес, телефон, часы работы, ссылки на Яндекс Карты, иконки Telegram, VK, WhatsApp + встроенная карта.
- **Форма записи** — имя, телефон (маска +7), выбор услуги и времени, чекбокс «Согласен с политикой конфиденциальности» со ссылкой на `policy.html`.
- **Финальный призыв** — короткий блок-CTA перед подвалом, который возвращает к форме.
- **Мобильная версия** — бургер-меню, одноколоночные сетки, галерея со свайпом, поля формы на всю ширину.
- **Страница политики** — самостоятельная страница с текстом в рамках 152-ФЗ, ссылки на неё из формы и подвала.

## Форма записи: что учтено

- вынесена на первый экран — видна без прокрутки (на мобильных сразу под заголовком);
- всего 4 обязательных поля + согласие, ничего лишнего;
- постоянные подписи к полям, а не только placeholder;
- `inputmode="tel"`, `autocomplete`, маска телефона `+7 (999) 999-99-99`;
- живая валидация: ошибка на blur, снятие по мере исправления, фокус на первом неверном поле при отправке;
- состояния `aria-invalid`, `aria-describedby`, `aria-busy`, `aria-live` для скринридеров;
- кнопка с индикатором отправки (`is-loading`), затем экран «Заявка принята» с фокусом на заголовке;
- скрытое поле-ловушка для спам-ботов;
- микротекст-подтверждение («перезвоним за 15 минут», «оплата в салоне», «ни к чему не обязывает») и альтернатива звонком.

## Как запустить

Просто откройте `index.html` двойным щелчком. Для корректной работы встроенной карты нужен интернет.

## Технические замечания

- Форма **демонстрационная**: данные никуда не отправляются. Для рабочей версии нужно подключить бэкенд или CRM — точка вставки помечена комментарием в `script.js` (`fetch()` в обработчике `submit`).
- Шрифты системные (без Google Fonts) — сайт не зависит от заблокированных в РФ CDN.
- Карта — **только Яндекс Карты**: интерактивный виджет (`yandex.ru/map-widget/v1/`) поверх статичного снимка (`static-maps.yandex.ru/1.x/`). Если виджет по какой-то причине не загрузится, пользователь всё равно увидит Яндекс-карту с меткой. Google Карт, Google Fonts и прочих Google-сервисов в проекте нет.
- Координаты карты (`37.5925, 55.751`) приблизительно соответствуют адресу демо-салона — подставьте реальные при сдаче проекта.
